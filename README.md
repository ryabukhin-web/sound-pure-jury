# Sound Pure Jury

Кабинет жюри конкурса «Чистый звук»: вход по логину/паролю и отборочный этап голосования за релизы.

## Стек

- **React 18** — UI
- **Vite** — сборка и dev-сервер

## Требования

- Node.js `>=18` (рекомендуется 20 LTS)
- npm `>=9` (или pnpm/yarn — см. lock-файл в корне)

## Запуск

```bash
# 1. установить зависимости
npm install

# 3. запустить dev-сервер
npm run dev
```
